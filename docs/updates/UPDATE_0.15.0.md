# INVEYS 0.15.0 — Pembaruan Grafik Holdings & Analisis Benchmark

Tanggal rilis: 9 Oktober 2026. Pembaruan ini menyempurnakan visualisasi grafik portofolio investasi (Holdings), penyatuan tooltip eksplorasi, stabilitas kurva saat data benchmark memiliki celah, serta pemilihan metrik Return vs Nilai Portofolio.

| Kemampuan | Status di INVEYS 0.15.0 | Batas praktis & Detail |
|---|---|---|
| Tampilan Grafik Holdings | Ringkasan nilai portofolio, shortcut periode (1d, 1w, 1m, 3m, 6m, YTD, 1y, ALL, Kustom) | Responsive chart dengan dukungan tema terang dan gelap |
| Pemilih Metrik Return vs Nilai | Beralih antara persentase return kumulatif dan nilai nominal portofolio | Nilai nominal menyembunyikan kurva perbandingan benchmark |
| Tooltip Terpadu & Interaktif | Crosshair penunjuk tanggal, klik untuk mengunci (*pin date*), kontrol keyboard dan sentuhan | Menampilkan rincian portofolio dan semua benchmark yang aktif |
| Penanganan Data Benchmark Celah | Benchmark dengan data jarang tidak lagi memotong kurva timeline portofolio | Warna benchmark konsisten, data kosong ditampilkan dengan tanda '—' |
| Drilldown Posisi Individual | Klik simbol aset dalam tabel kepemilikan untuk membuka grafik aset tersebut | Ekspor SVG dan CSV mengikuti tampilan dan filter yang sedang aktif |
