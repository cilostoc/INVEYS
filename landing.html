Pertanyaan Populer

Ada Pertanyaan? Kami Punya Jawabannya

Apakah data perbankan saya benar-benar aman di INVEYS? +
Sangat aman. INVEYS tidak pernah meminta username, PIN, atau password mobile banking Anda. Ekstraksi mutasi dilakukan secara offline-first melalui berkas e-statement PDF resmi yang Anda unduh dari bank Anda. Data tersebut disimpan terenkripsi di perangkat lokal Anda atau VPS pribadi Anda, bukan di database pihak ketiga.
Format dokumen bank apa saja yang didukung oleh AI INVEYS? +
AI INVEYS telah dioptimalkan khusus untuk membaca format e-statement PDF dan ekspor CSV dari Bank BCA, Bank Mandiri, Bank BRI (BritAma & Kartu Kredit), Bank BNI, Bank Jago, SeaBank, Superbank, blu BCA Digital, Jenius BTPN, Krom Bank, CIMB Niaga OCTO, Pegadaian Emas, serta struk belanja ritel seperti Indomaret dan Alfamart.
Apa perbedaan versi Cloud SaaS dengan Lisensi Lifetime Self-Hosted? +
Versi Cloud SaaS berjalan di cloud inveys.io kami sehingga Anda bisa langsung login tanpa perlu pusing urusan server. Sedangkan Lisensi Lifetime memberikan Anda kode dan paket Docker lengkap untuk Anda pasang di server VPS sendiri (Hostinger, DigitalOcean) atau komputer Anda seumur hidup dengan sekali pembayaran.
Apakah aplikasi ini bisa dijalankan tanpa koneksi internet? +
Ya! INVEYS dirancang dengan arsitektur Local-First. File aplikasi standalone inveys-app.html dapat Anda buka langsung di browser Chrome, Safari, atau Firefox di laptop Anda bahkan saat mode pesawat (offline) tanpa internet.
